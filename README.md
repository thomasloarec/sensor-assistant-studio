# Sensor Assistant Studio

Construis un banc de test interne Standex pour tester un assistant capteur.

Important :

- utilise mon projet Supabase existant comme backend ;

- n'active pas Lovable Cloud comme backend principal ;

- ne crée pas d'intégration MCP ;

- ne construis pas une interface publique prospect ;

- ne construis pas une landing page.

Le premier écran doit être l'outil de test interne :

conversation à gauche, onglets Sortie client / Trace interne / Revue / Données lead à droite.

Je vais te fournir le schéma Supabase V0.2, les scénarios de test et le contrat de réponse.

This project was built with [Lovable](https://lovable.dev).
