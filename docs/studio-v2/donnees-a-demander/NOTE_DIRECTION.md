# Sensor Studio : ce que nous livrons et ce que vos données débloquent

La première version utilise les données publiées disponibles pour comparer un montage aux distances de référence, rendre visibles les limites, préparer le dossier et produire une fiche de revue traçable. Elle conserve tous les capteurs visibles et indique où les données permettent un calcul.

Pour obtenir ensuite une prédiction 3D plus réaliste et une marge au pire cas défendable, nous demandons d'abord :

- **A, B, C : la géométrie active et les repères d'essai.** Où se trouve réellement l'aimantation dans M02, et d'où mesure-t-on les distances sur MK03 ?
- **D, E, F : les mesures et leur dispersion.** Mesures indépendantes, rémanence et variations entre lots permettent de passer du typique à une prédiction vérifiée.
- **O : les critères d'acceptation du bureau d'études.** Ils donnent un sens partagé à la validation.

Les données thermiques, les tolérances, le vieillissement et l'influence du métal (G à J) augmentent ensuite la fidélité dans l'application réelle. Les données K à N élargissent les usages et le catalogue.

Nous ne demandons pas ces données pour commencer : la V1 avance immédiatement. Nous les demandons pour préciser quels gains de réalisme et de fiabilité Standex souhaite financer et documenter. Chaque jeu reçu débloquera un domaine identifié, avec un rapport de contrôle et une version traçable.
